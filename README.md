# Exercícios de Lógica em Java com Interface Gráfica

Este repositório contém três exercícios simples desenvolvidos em Java, utilizando `JOptionPane` para entrada e saída de dados. Os exercícios abordam conceitos básicos de lógica de programação como estruturas condicionais, `switch`, laços de repetição e uso de constantes.

## Exercícios

### Exercício 1 - Sinal de um Número
- Solicita ao usuário um número.
- Exibe se o número é **positivo**, **negativo** ou **neutro**.

### Exercício 2 - Dia da Semana
- Solicita um número de 1 a 7.
- Utiliza `switch` e constantes para exibir o dia correspondente (domingo a sábado).

### Exercício 3 - Laços de Repetição
- Solicita um número.
- Exibe os números de 0 até o valor informado usando:
  - Laço `for`
  - Laço `while`
  - Laço `do-while`

## Tecnologias
- Java (versão 8+)
- `javax.swing.JOptionPane` para GUI simples
- Organização em pacotes por exercício
